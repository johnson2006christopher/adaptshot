    # AdaptShot Documentation

**Human-aligned, CPU-first few-shot vision learning for resource-constrained environments**

AdaptShot is an open-source Python library that enables reliable image classification with fewer than 50 examples per class, calibrated uncertainty tracking, and continuous learning through human feedback. It is engineered from the ground up to run on standard CPUs with minimal memory overhead, requiring no cloud connectivity or GPU hardware.

---

## 📦 Installation

AdaptShot requires Python ≥ 3.9. Install the stable release via pip:

```bash
pip install adaptshot

    Optional extras for edge acceleration and interactive pilots: 

    pip install adaptshot[faiss,ui]

    ??? info "Development Installation" For contributors or local development: 

    git clone https://github.com/johnson2006christopher/adaptshot.git
cd adaptshot
pip install -e ".[dev]"

    🚀 Quick Start¶

    Initialize a learner, load a small support set, and run inference with calibrated confidence:

    from adaptshot import FewShotLearner

# Initialize with CPU defaults and deterministic seeding
learner = FewShotLearner(
    classes=["maize_healthy", "maize_blight", "cassava_virus"],
    device="cpu",
    seed=42
)

# Load 10 support images per class
learner.load_support_images(
    image_paths=["healthy/1.jpg", "blight/1.jpg", "virus/1.jpg", ...],
    labels=["maize_healthy", "maize_blight", "cassava_virus", ...]
)

# Predict on a new image
result = learner.predict("field_photo.jpg")
print(f"Prediction: {result.prediction}")
print(f"Calibrated Confidence: {result.calibrated_confidence:.2%}")
print(f"Requires Review: {result.uncertainty_flag}")

    🧠 Core Capabilities (v0.1.0)¶

    The following components are implemented, tested, and available in the current release:

    Component Function Status
    FewShotLearner Unified inference API with embedding extraction, similarity search, and state persistence ✅ Stable
    CalibrationEngine Online temperature scaling + sliding-window Expected Calibration Error (ECE) tracking ✅ Stable
    ACTEngine Adaptive Confidence Thresholding with dynamic per-class decision gates ✅ Stable
    FeedbackRouter Human correction ingestion, batch accumulation, and fine-tune triggering ✅ Stable
    CAEWCFinetuner Correction-Aware Elastic Weight Consolidation for head-only continual learning ✅ Stable
    UPUGFPruner Uncertainty-Guided Forgetting for bounded replay buffer management ✅ Stable
    Gradio Pilot UI Interactive dashboard for field testing and human feedback collection ✅ Stable

    Design Constraints

    • CPU-first: All core operations run on CPU by default. CUDA is supported but not required.
    • Memory-bound: Full pipeline operates within <250MB RAM on standard hardware.
    • Offline-capable: Zero cloud API calls during inference, calibration, or fine-tuning.
    • Backbones: resnet18 and mobilenet_v3_small (ImageNet-pretrained, frozen).

    🌍 Project Status & Governance¶

    • Current Release: v0.1.0 (Published: 2026-05-15)
    • License: MIT
    • Python Support: 3.9, 3.10, 3.11, 3.12
    • Development Status: Active. All features are reproducible via pytest and deterministic benchmarks.
    • Security: Local-only processing by default. No telemetry, no external data transmission.
    • Governance: Open RFC process. Community-driven. See CONTRIBUTING.md for participation guidelines.

    Known Limitations (v0.1.0)

    • FAISS-CPU is optional; NumPy fallback is used by default.
    • UP-UGF pruning falls back to FIFO eviction during initial buffer population.
    • Calibration requires ≥10 predictions before temperature refitting stabilizes.
    • ONNX export and mobile SDKs are not yet implemented (planned for v0.2.0).
